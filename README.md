# Basic C Programming

This repository contains examples and exercises focused on the fundamentals of the C programming language. It was created to practice programming logic, understand basic concepts, and develop problem-solving skills through hands-on coding.

## 📚 Topics Covered

- **Variables and Data Types** — Variable declaration, initialization, and basic data types.
- **Operators** — Arithmetic, relational, logical, and assignment operators.
- **Conditional Structures** — Decision-making using `if`, `else`, and `switch`.
- **Loops** — Repetition structures using `for`, `while`, and `do-while`.
- **Functions** — Function declaration, definition, parameters, and return values.
- **Exercises and Examples** — Practical exercises to reinforce programming concepts.

## 🎯 Purpose

The main goal of this repository is to build a solid foundation in C programming through practice and experimentation. It serves as a learning resource for beginners who want to improve their programming logic and become familiar with the language.

## 🛠️ Technologies

- **Language:** C
- **Compiler:** GCC (or any compatible C compiler)
